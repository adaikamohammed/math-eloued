# 03. محفظة العائلة الذكية وفضاء الأولياء 👨‍👩‍👧‍👦💼

## 1. فلسفة التصميم: لماذا تم ابتكار محفظة العائلة؟
- **التحدي الميداني السابق:** كان حفظ كود الأستاذ يتم محلياً في جهاز الولي (LocalStorage)، مما يعني أن الأب إذا فتح المنصة في هاتفه وحفظ أستاذ ابنه، فإن الأم في هاتفها لا تجد الأستاذ، وإذا كان للعائلة 3 أبناء في أطوار مختلفة يضيع الأولياء في حفظ الأكواد المتعددة.
- **الحل الذكي الأول (المعتمد):** بدلاً من إجبار الولي على إنشاء حساب إلكتروني بكلمة مرور وإجراءات تسجيل دخول قد تشكل عائقاً أمام بعض الأولياء، تم ابتكار **محفظة العائلة الذكية القابلة للمشاركة والتزامن السحابي الفوري**:
  - يتم تجميع كافة أساتذة الأبناء (الرياضيات، العربية، العلوم...) في محفظة واحدة.
  - توليد رابط عائلي مشفر خاص بالعائلة:
    `https://jusoor-dz.vercel.app/family?data=...`
  - يمكن للأب إرسال هذا الرابط إلى الأم أو العكس عبر تطبيق **WhatsApp** أو **Viber** أو SMS.
  - بمجرد نقر الطرف الآخر على الرابط، يتم فك تشفير المحفظة وحفظ كافة الأساتذة في هاتفه فوراً وتلقائياً!

## 2. الهندسة التقنية لبروتوكول المحفظة المشفرة (`src/lib/familyWallet.ts`)
- **تشفير Base64url الآمن المتوافق:**
  - تم بناء دوال تشفير وفك تشفير متوافقة بنسبة 100% بين خادم Node.js وبيئة المتصفح:
    ```typescript
    export function toBase64Url(str: string): string {
      const bytes = new TextEncoder().encode(str);
      let bin = "";
      for (let i = 0; i < bytes.length; i++) {
        bin += String.fromCharCode(bytes[i]);
      }
      return btoa(bin)
        .replace(/\+/g, "-")
        .replace(/\//g, "_")
        .replace(/=+$/, "");
    }
    ```
- **هيكل بيانات المحفظة العائلية:**
  - كل عنصر يمثل أستاذ ابن معين، ويحتوي على: `code`, `slug`, `name`, `subject`, `wilaya`, `school`, `childName` (اختياري).
- **منع تكرار المفاتيح في React:**
  - تم اعتماد مفتاح فريد مركب في بطاقات المحفظة (`key={`${teacher.slug || teacher.code}-${index}}``) لمنع تضارب المفاتيح وأخطاء React عند تكرار نفس الأستاذ لأكثر من ابن.
