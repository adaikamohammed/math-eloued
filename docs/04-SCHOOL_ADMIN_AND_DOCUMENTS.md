# 04. إدارة المؤسسة والوثائق الرسمية والمطبوعات الإعلانية 🏛️📄

## 1. التجسيد الميداني في متوسطة باهي علي
- **المؤسسة:** متوسطة باهي علي — بلدية الرقيبة / مديرية التربية لولاية الوادي.
- **الهدف الميداني:** تعليق مطبوعات رسمية ملونة واحترافية في قاعة الأساتذة لتعريف الزملاء الأساتذة بالمنصة، وحثهم على الانضمام واعتماد كود الأستاذ الخاص بهم، مع دليل مصور تفصيلي يشرح لهم كل خطوة بدقة.

---

## 2. الملصق الإعلاني الرسمي لقاعة الأساتذة (A4 Poster)
- **الترويسة الرسمية المعتمدة:**
  - الجمهورية الجزائرية الديمقراطية الشعبية
  - وزارة التربية الوطنية — مديرية التربية لولاية الوادي
  - **متوسطة باهي علي**
- **الأسلوب الترحيبي الراقي:**
  - تم صياغة الإعلان بأسلوب ترحيبي مهني يحترم مكانة الأستاذ ودوره التربوي:
    > «يسر إدارة المؤسسة الترحيب بكافة السيدات والسادة أساتذة المؤسسة الكرام للانضمام لفضائهم التعليمي، متمنين للجميع كل التوفيق والتميز»
  - تجنب أي أسلوب أمر أو توجيه إداري إلزامي.
- **العناصر البصرية:**
  - رمز QR فائق الدقة لمسح رابط المنصة فوراً بكاميرا الهاتف الذكي.
  - استعراض لأبرز ميزات المنصة (رقمنة السبورة، الدفتر اليومي، التنقيط الصفي بلمسة واحدة، لوحة الشرف).
  - خانة اعتماد وتوقيع السيد مدير المتوسطة مع الختم الرسمي.

## 3. الدليل المصور العملي للأساتذة (A4 Step-by-Step Guide)
دليل مصور من 3 صفحات شاملة يوضح للأستاذ كيفية التعامل مع المنصة خطوة بخطوة بالصور الكاملة غير المقصوصة مع تظليل واضح لموضع النقر في الشريط الجانبي:
1. **الخطوة 01 — إنشاء حساب الأستاذ:** نافذة إنشاء الحساب، اختيار مادة التدريس، ولاية الوادي، متوسطة باهي علي، وكلمة المرور.
2. **الخطوة 02 — فضاء الأستاذ وكود المادة:** معرفة كود الأستاذ الخاص (مثل `MTH-784`) ورابط فضاء التلاميذ ومواعيد الاستقبال.
3. **الخطوة 03 — إدارة الأفواج والتلاميذ:** تقسيم الأفواج (1م1، 1م2...) وتوزيع التفويج (فوج 1 / فوج 2).
4. **الخطوة 04 — كراس الدروس والسبورة الرقمية:** رفع صور السبورة والملخصات لخدمة التلميذ الغائب.
5. **الخطوة 05 — دفتر التقويم المستمر الصفي:** التنقيط السريع بالأصبع في القسم والزر الذهبي لوضع العلامة الكاملة.
6. **الخطوة 06 — الدفتر اليومي وسيرورة الحصص:** توثيق الحصص (تمهيدي، وسيطي، نهائي) وتكرار الدروس للأفواج المتوازية.

  npm run generate:pdf
